# 📊 Investro – Stock Market Website Prototype

Investro is a modern stock market web application prototype that allows users to explore, analyze, and interact with stock market data in a simple and intuitive way. This project is designed to simplify stock analysis and provide a smooth user experience for beginners as well as intermediate users.

---

## 🚀 Features

* 📈 Stock market data visualization
* 🔍 Explore and analyze different stocks
* 💡 Clean and user-friendly interface
* ⚡ Fast and responsive performance
* 📊 Prototype for stock buying and selling system

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Node.js
* **Language:** TypeScript
* **Package Manager:** pnpm

---

## 📁 Project Structure

```
├── lib/                # Core application logic
├── scripts/            # Helper and utility scripts
├── attached_assets/    # Images and assets
├── artifacts/          # Build/output files
├── package.json        # Dependencies and scripts
├── tsconfig.json       # TypeScript configuration
├── pnpm-lock.yaml      # Dependency lock file
```

---

## ⚙️ Installation & Setup

1. Clone the repository:

```
git clone https://github.com/DivyaKumarSharma-jpg/Stock-Market-Website-Prototype.git
```

2. Navigate to the project folder:

```
cd Stock-Market-Website-Prototype
```

3. Install dependencies:

```
pnpm install
```

4. Run the project:

```
pnpm start
```
